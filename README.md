# ShipThresh

A small WooCommerce plugin that shows a free-shipping progress message on the checkout page — "Spend €X more to get free shipping!" — with the message text and spend threshold editable from the WordPress admin.

**Author:** Bananalytics

---

## What it does

- Adds a notice above the checkout form showing how much more a customer needs to spend to reach free shipping.
- Once the cart subtotal reaches the threshold, shows a configurable success message instead.
- Renders a simple progress bar alongside the message.
- All text and the threshold amount are editable at **Settings → ShipThresh** — no code changes needed to update copy or the €amount.

## Requirements

- WordPress
- WooCommerce (the plugin no-ops with an admin notice if WooCommerce isn't active)

## Installation

1. Download or clone this repository.
2. Zip the `shipthresh` folder, or upload it directly via SFTP to `wp-content/plugins/`.
3. In WordPress admin: **Plugins → Add New → Upload Plugin** (if using a zip), or activate directly from **Plugins** if uploaded via SFTP.
4. Go to **Settings → ShipThresh** to set the threshold and message text.

## Settings

Found at **Settings → ShipThresh** (requires the `manage_woocommerce` capability — shop managers and admins).

| Field | Description |
|---|---|
| Free shipping threshold (€) | Cart subtotal (excl. tax) required to unlock free shipping. |
| Progress message | Shown while below the threshold. Supports `{remaining}` and `{threshold}` placeholders, which are replaced with formatted prices in the store's currency. |
| Success message | Shown once the threshold is reached. |

Example progress message: `Spend {remaining} more to get free shipping!`

## How it works

1. `ShipThresh_Settings` registers the option `shipthresh_settings` (an array: `threshold`, `progress_message`, `success_message`) via the WordPress Settings API.
2. On `woocommerce_before_checkout_form`, `ShipThresh_Notice` reads the cart subtotal via `WC()->cart->get_subtotal()` and compares it to the configured threshold.
3. Below threshold: renders the progress message with `{remaining}`/`{threshold}` swapped for `wc_price()`-formatted amounts, plus a proportional progress bar.
4. At or above threshold: renders the success message instead, with the bar full.

## Security notes

- The settings page is gated on the `manage_woocommerce` capability, checked both when registering the admin menu page and again when rendering it.
- Settings are saved through the WordPress Settings API (`options.php`), which verifies the nonce and referrer generated by `settings_fields()` before any write.
- Every field has its own `sanitize_callback` logic: the threshold is cast to a float and clamped to `>= 0`; message fields go through `sanitize_text_field()`. A missing or invalid field falls back to the previously stored value rather than raw request input, so a malformed submission can't null out existing settings.
- Message output on the frontend goes through `wp_kses_post()` (needed because `wc_price()` returns HTML for currency formatting); all admin-page field values are escaped with `esc_attr()`/`esc_html()` on output.
